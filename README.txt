M. BURHAN ALI — RESPONSIVE RESUME WEBSITE
=========================================

FILES
index.html — page structure and content
style.css — styling, mobile layout, light/dark themes
script.js — interactive menu, theme toggle, project filters, email copy
assets/Burhan_Ali_CV.pdf — original CV for the Download CV button
assets/favicon.svg — browser tab icon

HOW TO OPEN
1. Extract the ZIP file.
2. Open the Burhan_Resume_Website folder in Visual Studio Code.
3. Open index.html with Live Server (VS Code extension), or open index.html in a browser.
4. Check the mobile menu, theme button, project filters, Download CV link and WhatsApp chat icon.

PUBLISH ON GITHUB PAGES
1. Sign in to github.com and create a new PUBLIC repository (example: burhan-resume).
2. Upload index.html, style.css, script.js and the assets folder to the repository ROOT.
3. Open repository Settings > Pages. Choose Deploy from a branch.
4. Choose branch main and folder / (root). Save.
5. After publishing completes, open the URL that GitHub Pages shows. For example:
   https://YOUR-USERNAME.github.io/burhan-resume/
6. Paste the real repository and live site URLs into the assignment Word file.
